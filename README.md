# 本厚木・単身者の可処分所得と生活設計シミュレーション

単身者（神奈川県厚木市・本厚木駅徒歩10分圏在住）の可処分所得・生活費・貯蓄可能額・住宅購入・35年後の資産価値までを試算したHTMLレポート。**年収600万円／800万円／1,000万円**をページ上部のプルダウンで切り替えられる。

- **公開URL**: https://kahoo-de3.github.io/honatsugi-life-cost/ … GitHub Pagesで公開中。GitHubアカウントなしで誰でも閲覧できる。
- **成果物**: [`index.html`](./index.html) … 単一ファイルで完結（外部依存なし・ライト/ダークテーマ対応）。ブラウザで開くだけで表示できる。
- **年収の切り替え**: プルダウンを変えると、①②④の金額・グラフ・表・見出し・前提条件がすべて再計算される。③の平均年収478万円は比較対象として固定。⑤は年収に依存しない。
- **グラフ**: 棒グラフ・円グラフはHTML/SVG＋バニラJavaScriptで描画。金額は `index.html` 末尾の `<script>` 内の `calc()` が税制ルールから算出する（ハードコードではない）。

## 編集の仕方（別PCのClaude Codeでも継続可能）

1. このリポジトリをクローン: `git clone https://github.com/kahoo-de3/honatsugi-life-cost.git`
2. Claude Code / Claude で `index.html` を開いて編集
3. **税・社会保険料の計算を変える**とき … `<script>` 内の `calc()` と、その上の `GRADES`（標準報酬月額）／`salaryDeduction()`（給与所得控除）／`basicDeductionTax()`（基礎控除）／`TAX_BRACKETS`（所得税速算表）を編集
4. **生活費・住宅費を変える**とき … `LIVING_Y` / `LIVING_M`（②賃貸モデル）、`BUY_LIVING_Y` / `BUY_LIVING_M`（④購入モデル）と、`slices2`〜`slices7` の各項目、および②の生活費内訳テーブル（HTML側）を編集
5. **選択できる年収を増やす**とき … `<select id="grossSelect">` に `<option>` を追加するだけでよい（計算・描画は自動追従）
6. 本文中の固定テキストは `render()` 内の `setText()` / `setHtml()` でまとめて生成しているので、文言の変更はそこで行う
7. 前提を変えるときは本READMEの数値と `index.html` を両方あわせて更新すること
8. `git push` すると GitHub Pages（`main` ブランチのルート）に自動反映される（反映まで数十秒〜1分）

## 共通の前提条件

- 単身者・40歳未満（介護保険料なし）・扶養親族なし
- 賞与なし（年収を12等分して毎月支給）と仮定。標準報酬月額は協会けんぽの等級表から自動判定（厚生年金は上限65万円）
- 健康保険は協会けんぽ・神奈川県（令和7年度 料率9.92%、労使折半）
- 所得控除は社会保険料控除と基礎控除のみ（iDeCo・生命保険料控除・ふるさと納税等は考慮せず）
- 所得税は令和7年分。基礎控除は令和7・8年分の上乗せ特例を反映し、合計所得に応じて58万〜95万円が自動適用される
- 住民税は厚木市の令和8年度分（基礎控除43万円）
- 住民税に神奈川県の水源環境保全・再生のための超過課税（所得割+0.025%・均等割+300円）を反映

## ③ 平均年収478万円の場合（生活費据え置き）

- 平均年収478万円 = 国税庁「令和6年分 民間給与実態統計調査」の平均給与（過去最高）
- 標準報酬月額41万円、所得税の基礎控除は68万円（令和7・8年分の上乗せ後）で計算
- 社会保険料720,480／所得税102,900／住民税226,500 → **可処分所得 3,730,120円（78.0%）**
- 生活費を②のまま据え置き → **貯蓄可能額 1,006,120円（27.0%）**
- 選択年収との差: 600万円比 ▲895,480円（約47%減）／800万円比 ▲2,209,880円（約69%減）／1,000万円比 ▲3,536,280円（約78%減）

## ④ 自宅購入（メイツ本厚木）

- 物件: 明和地所「メイツ本厚木」本厚木駅徒歩5分・2026年9月下旬入居予定。1DK・34㎡台（3,300万円台〜）を **3,350万円と仮定**（管理費・修繕積立金・税額等は非公表のため推測値）
- **ⅰ 購入総額**: 約3,540万円（物件3,350万円＋諸費用 約190万円）
- **ⅱ フラット35（全期間固定・頭金なし）**: 金利 **年3.25%**（2026年7月・融資率9割超の最多金利）、35年元利均等、月返済133,643円、総返済56,130,060円、諸費用込み総負担 約5,803万円
- **ⅲ 月/年負担**: 月163,143円（ローン133,643＋管理費10,000＋修繕積立7,000＋固都税12,500）／年1,957,716円
- 34㎡のため不動産取得税・固定資産税の新築軽減（50㎡以上要件）と住宅ローン控除（40㎡以上要件）はいずれも対象外
- 生活費＋住宅費の合計は年3,925,716円（②の家賃・更新料を住宅費に置換）。賃貸との差は年収によらず **▲1,201,716円**
- 購入した場合の貯蓄可能額:

| | 年収600万円 | 年収800万円 | 年収1,000万円 |
|---|---:|---:|---:|
| 貯蓄可能額（年） | 699,884円 | 2,014,284円 | 3,340,684円 |
| 可処分所得比 | 15.1% | 33.9% | 46.0% |

- 平均年収478万円で購入: 生活費＋住宅費 3,925,716円 > 可処分所得 3,730,120円 → **年▲195,596円の赤字**

## ⑤ 35年後の資産価値

- 本厚木駅周辺の築30〜35年中古マンション相場（2026年2月時点）から推定
- 想定資産価値 **約600万円**（レンジ400万〜700万円、34㎡×㎡単価12〜20万円）。新築3,350万円から **▲2,750万円（約▲82%）**
- 35年総負担 約7,042万円 − 売却想定600万円 = 実質住居コスト 約6,442万円
- 将来の市況・金利・人口動態・管理状態により大きく変動し得る
